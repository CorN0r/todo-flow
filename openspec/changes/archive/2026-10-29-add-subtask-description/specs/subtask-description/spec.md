## Purpose

为子任务提供描述(执行说明)的展示与编辑:消费 AI 拆解写入子任务描述字段的纯文本说明,在列表展开区与任务详情两处以一致的交互查看与修改;删除撤销重建不丢描述。

## ADDED Requirements

### Requirement: 展示

子任务行 MUST 在标题下方为非空描述渲染单行截断预览,展示文本 MUST 经 HTML 剥离归一为纯文本;描述为空的子任务 MUST NOT 占用额外空间。列表展开区与任务详情两处 MUST 呈现一致样式。

#### Scenario: AI 拆解采纳后查看
- **WHEN** 用户采纳 AI 拆解候选后展开子任务列表或打开任务详情
- **THEN** 每条带执行说明的子任务在标题下方显示单行截断预览

#### Scenario: 历史富文本描述
- **WHEN** 子任务描述字段存有 HTML 富文本
- **THEN** 预览显示剥离标签后的纯文本

### Requirement: 编辑入口与编辑态

编辑入口 MUST 包含:点击描述预览(已有描述时)、列表子任务右键菜单"编辑描述"项、两处行尾悬停图标(有描述着品牌色、无描述灰色)。编辑态 MUST 为纯文本 textarea,初值为剥离 HTML 后的当前描述,进入时自动聚焦且光标置于末尾;textarea 内 Enter MUST 为换行。列表中编辑描述时 MUST 禁用该行拖拽排序,并与标题行内编辑互斥。

#### Scenario: 为无描述子任务添加说明
- **WHEN** 用户经右键菜单或行尾图标对无描述子任务发起编辑并输入内容
- **THEN** 该行展开编辑区,输入经保存语义落库后预览出现

#### Scenario: 编辑时拖拽
- **WHEN** 列表展开区某子任务正处于描述编辑态
- **THEN** 该行不可被拖拽排序,行尾日期/提醒入口收起

### Requirement: 保存语义

描述编辑 MUST 以失焦提交:仅当值与当前描述(剥离 HTML 后)不同时调用既有任务更新流程且 MUST 仅修改描述字段;Esc MUST 还原初值并退出不保存;清空后失焦 MUST 保存空字符串。

#### Scenario: 未修改即失焦
- **WHEN** 用户进入编辑未改动内容即点击别处
- **THEN** 不发起任何保存请求

#### Scenario: Esc 放弃修改
- **WHEN** 用户修改后按 Esc
- **THEN** 编辑区收起,原描述保持不变

### Requirement: 删除撤销保留描述

删除任务或子任务后的撤销重建 MUST 回传被删对象的描述;删除带子任务的父任务后撤销,MUST 逐条回传子任务的描述。

#### Scenario: 撤销删除带说明的子任务
- **WHEN** 用户删除一条带执行说明的子任务并点击撤销
- **THEN** 重建的子任务标题与描述均与删除前一致
