# ai-model-access Specification

## Purpose

为 TodoFlow 的内置 AI 功能提供可复用的模型接入能力:本地管理服务连接、模型条目与全局默认模型,经系统凭证存储保管 API Key,以统一契约调用 OpenAI 兼容服务并管理调用生命周期、错误分类、能力验证与有限诊断摘要。

## Requirements

### Requirement: 本地模型配置管理

系统 MUST 支持创建、编辑、停用和删除多组服务连接(显示名称、协议类型、API 基础地址、凭证引用),同一连接下挂多个模型条目(服务端模型标识、显示名称)。连接、模型、默认选择、验证状态与调用摘要 MUST 按设备本地保存,不进入任务同步白名单,不跨端同步。

#### Scenario: 重启后配置保留
- **WHEN** 用户创建多个服务与多个模型,手动选择默认模型,重启应用
- **THEN** 非敏感配置与默认选择保持不变,凭证通过本机凭证存储依然可用

#### Scenario: 修改使验证结论过期
- **WHEN** 用户修改连接地址、模型标识、凭证或影响请求的参数
- **THEN** 该配置既有验证结论标记为已过期;仅修改显示名称不使验证过期

### Requirement: 凭证安全存储

系统 MUST 通过操作系统凭证存储保存、替换、删除 API Key,普通配置只保存凭证引用。系统 MUST NOT 提供前端读取原始 Key 的接口,MUST NOT 将 Key 写入数据库、任务同步数据或整库备份。凭证缺失、已配置与测试失败 MUST 显示为不同状态;凭证持久化失败时 MUST NOT 显示为保存成功。修改连接目标来源后 MUST 要求重新填写凭证,不自动沿用旧 Key。

#### Scenario: 备份不含凭证
- **WHEN** 用户读取全部普通设置或执行数据库备份
- **THEN** 输出中不包含任何原始 Key

#### Scenario: 引用存在但凭证丢失
- **WHEN** 配置引用了凭证但本机凭证存储中查询不到
- **THEN** 界面显示"需要重新填写 Key",而不是显示为已配置

#### Scenario: 凭证写入失败
- **WHEN** 系统凭证存储写入失败
- **THEN** 保存流程报告失败,不显示保存完成,不留下指向不存在凭证的可用默认引用

### Requirement: 全局默认模型

系统 MUST 支持为每台设备选择一个全局默认模型,可为空;首个模型保存后 MUST NOT 在后台自动改变用户既有选择。删除或停用默认模型前 MUST 要求选择替代模型或明确清空默认选择。模型临时不可用时 MUST 显示原因,MUST NOT 自动切换到其他服务。

#### Scenario: 手动选择默认模型
- **WHEN** 用户在多个已保存模型中手动设置默认模型
- **THEN** 所有 AI 功能共用该默认模型,选择持久保留

### Requirement: 统一调用契约与生命周期

系统 MUST 将统一生成请求转换为已配置服务的协议(首版为 OpenAI 兼容 Chat Completions),返回规范化结果(文本、完成原因、实际模型标识、可选用量;用量缺失显示为未知,不显示为零)。每次调用 MUST 固定请求快照,调用中更改全局默认模型不影响已发出请求。系统 MUST 支持取消(停止等待、接收与处理,不承诺远端撤回)、单次总超时(默认 120 秒,可在高级设置调整)、用户请求与测试合计至多两个并发槽位。取消后到达的晚响应 MUST NOT 覆盖界面或触发任务写入。流式进度 MUST 仅发给发起请求的窗口,按请求标识关联。网络请求期间 MUST NOT 持有数据库锁。不默认发送服务不支持的可选参数;本地 MUST 限制输入与响应体大小。

#### Scenario: 生成中切换默认模型
- **WHEN** 请求发出后用户切换默认模型或修改连接
- **THEN** 该请求继续使用原快照完成,后续请求使用新配置

#### Scenario: 取消后晚响应到达
- **WHEN** 用户取消流式生成后服务响应到达
- **THEN** 界面不更新为成功,不创建任务,结果不串入其他窗口

#### Scenario: 输出被截断
- **WHEN** 服务返回内容被截断、拒绝处理或结构不合法
- **THEN** 结果区分标注,截断或中断的结构化输出不作为完整业务结果输出

### Requirement: 机器可读错误分类

模型调用失败时系统 MUST 返回机器可读错误码、用户可读说明与脱敏诊断信息,至少区分:配置缺失、凭证不可用、鉴权失败、模型不可用、连接失败、限流、超时、取消、不支持的能力、输出截断、格式不合法。系统 MUST NOT 自动重试或自动切换服务;失败后用户可手动重试。

#### Scenario: Key 错误
- **WHEN** 服务返回鉴权失败
- **THEN** 界面显示鉴权失败分类,不自动换服务,普通任务功能不受影响

#### Scenario: 断网或超时
- **WHEN** 网络不可达或超过总超时
- **THEN** 显示连接失败或超时分类,既有功能继续工作

### Requirement: 能力验证

系统 MUST 分层显示三类状态:配置已保存、基础调用通过(该配置完成过一次真实文本生成)、功能验证通过(结果通过功能本地校验)。首版验证基础文本生成、流式接收与任务拆解样例结构,验证输入 MUST 为固定短小、不含用户任务内容的文本。每次验证 MUST 绑定配置指纹(协议、规范化地址、模型标识、影响请求的参数与凭证版本)和时间;配置变化后不沿用之前成功标记。验证失败 MUST NOT 删除用户配置;流式验证失败 MUST NOT 在未声明的情况下以非流式结果冒充流式通过。

#### Scenario: 验证连接
- **WHEN** 用户对某模型执行"验证连接"
- **THEN** 系统用固定测试输入对该模型发起实际生成,显示结果、耗时与服务返回用量(如有)

#### Scenario: 验证任务拆解
- **WHEN** 用户执行"验证任务拆解"
- **THEN** 系统用内置虚构任务生成并按业务结构校验,显示通过或失败

### Requirement: 模型列表获取

系统 MUST 支持从服务获取模型列表,也始终允许手动填写模型标识。列表获取失败时 MUST NOT 清空已保存模型,MUST NOT 据此认定生成接口不可用。

#### Scenario: 列表接口不可用
- **WHEN** 模型列表接口失败但用户手填模型标识
- **THEN** 该模型仍可保存与验证

### Requirement: 调用诊断摘要

系统 MUST 保存简要调用摘要(用途、时间、模型与连接标识、状态、耗时、错误分类、服务实际返回用量),保留最近 30 天且至多 1000 条,并提供清除入口。系统 MUST NOT 保存 Authorization、Key、完整请求头、完整请求正文、完整模型输出或未经处理的错误响应体。删除调用摘要 MUST NOT 影响已采纳子任务或采纳回执。

#### Scenario: 清理调用摘要
- **WHEN** 用户清除调用摘要或重启应用
- **THEN** 不恢复完整输入输出,已采纳任务与重复操作保护不受影响

### Requirement: 配置界面

系统 MUST 在"设置 → AI 模型"提供独立页面:服务连接列表、模型列表、全局默认模型与最近调用状态。新增服务时提供常用云服务预设(智谱 GLM Coding 套餐、OpenAI、DeepSeek、Gemini)与自定义兼容服务入口;预设仅预填地址与接口选项。API 地址明确表示基础地址,系统在其后拼接对话端点路径,MUST NOT 统一强加版本段,也 MUST NOT 丢弃用户填写的基础路径;用户误填完整端点地址时 MUST 提示修正。未经验收的预设 MUST NOT 标记为已验证。高级选项区收起超时等参数,普通用户完成必填项即可使用。

#### Scenario: 基础地址包含版本前缀
- **WHEN** 用户填写的基础地址已含版本或兼容前缀
- **THEN** 系统正确保留基础路径,不重复或误加版本段

#### Scenario: 误填完整端点
- **WHEN** 用户把完整对话端点地址填入基础地址
- **THEN** 系统提示修正,不产生重复拼接

### Requirement: 备份与导入边界

整库备份 MUST NOT 包含凭证本体(可含非敏感配置与凭证引用)。导入其他任务数据库 MUST NOT 覆盖本机模型配置;若恢复后凭证引用失效,系统 MUST 提示重新配置凭证。

#### Scenario: 导入任务数据库
- **WHEN** 用户导入整库备份
- **THEN** 本机模型连接、模型与默认选择保持不变
